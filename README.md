# Grade Calculator GUI
An expansion of the simple grade calculator for students, written in Python.

<img src="https://github.com/zhinch2/grade-calculator-gui/blob/main/example-image.png" alt="example-image" width="300">

## Prerequisites
Before running the grade calculator GUI python script, you **must have Python 3.0 or later** installed.
- Download the latest version at [https://www.python.org/downloads/](https://www.python.org/downloads/)
- Or [click here](https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix) to download the installer (26.3).
- You can check what version you have by running `python --version`

## How to use
### Method 1: git clone
1. Open the terminal and navigate into your desired folder using `cd`.
2. Clone the repository using

   ```
   git clone https://github.com/zhinch2/grade-calculator-gui.git
   ```
4. Run the `Grade_Calculator_GUI.py` file.

> [!IMPORTANT]
> You must already have [git](https://git-scm.com/) installed to use git clone. If not, use method 2.

### Method 2: latest release
1. Go the [latest release](https://github.com/zhinch2/grade-calculator-gui/releases/latest) page.
2. Download and run the `Grade_Calculator_GUI.py` file.

## Troubleshooting
- If the python file opens in VS Code or another text editing software, you can force it to open with Python by right-clicking on the file, clicking 'Open with' and selecting Python.
